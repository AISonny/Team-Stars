呈現 ACTIVE、SHORT_IDLE、INACTIVE、LONG_IDLE、BREAK_DUE、BREAK_PAUSED、PAUSED、LOCKED、SUSPENDED、RESUMING 與 STOPPED 之生命週期。

圖三：45 分鐘健康提醒觸發與 5 大處置按鈕流程圖 (Flowchart)

呈現唯一提醒 ID 生成、Toast 通知與桌面彈窗觸發，以及五大按鈕各自對計時週期、延後排程與暫停的處置邏輯。

flowchart TD Due[本輪有效活動達 45 分鐘] --> LockEngine[計時引擎鎖定累計
狀態轉為 BREAK_DUE] LockEngine --> GenID[產生唯一提醒 ID：break-uuid] GenID --> NoticeService[發送 Windows 11 Toast 系統橫幅通知] GenID --> PopWindow[顯示現代化桌面彈出視窗
提供喝水、肩頸伸展引導] PopWindow --> UserChoice{使用者點選處置按鈕} UserChoice -- 按鈕 1：我已完成健康休息 --> ActionComplete[1. 本輪累計歸零 (00:00:00)
2. 今日完成休息次數 +1
3. 開啟新一輪 45 分鐘計時
4. 關閉彈窗] UserChoice -- 按鈕 2：稍後 5 分鐘提醒 --> ActionSnooze[1. 設定延後時限 (Now + 300s)
2. 延後期間維持閒置不累計
3. 關閉彈窗，到期後再次提醒] UserChoice -- 按鈕 3：我正在休息中 --> ActionResting[1. 狀態切換為 BREAK_PAUSED
2. 完整保留 45 分鐘進度
3. 主介面顯示「休息中」
4. 等待使用者按下「結束休息」] UserChoice -- 按鈕 4：僅關閉視窗 --> ActionDismiss[1. 僅隱藏當前對話框
2. 維持 BREAK_DUE 狀態
3. 不默認完成休息，保留待處理] UserChoice -- 按鈕 5：暫停提醒 --> ActionPause[1. 狀態切換為 PAUSED
2. 凍結後續計時與彈窗
3. 需使用者手動點擊「恢復計時」] ActionComplete --> NextCycle([開始新週期 ACTIVE]) ActionSnooze --> WaitSnooze([等待 5 分鐘倒數]) ActionResting --> WaitUserEnd([等待點擊「結束休息」]) ActionDismiss --> StayPending([隨時可由系統匣重新喚出]) ActionPause --> ManualPaused([維持暫停狀態])
